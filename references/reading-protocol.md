# 原书全面读取与解读协议

## 阅读范围

每次新的原书解读重新制作读取包，重新从 PDF 读取，而不是从旧答案回忆。若只是问一般画法/规则、不解本书内容，可只执行起卦规则模式。

必读集合：

1. PDF 1–10 页：覆盖封面、目录、前言、通则等全部前置页。不能只读一段“序”并称前言全读。
2. 主卦从章节首页到下一卦前一页的完整章节，包含图像、图中说明、卦图象解、卦序解释、卦辞、彖象、全部爻辞及各段解释。
3. 变卦已知时，其完整章节同上；静卦主变相同不重复。
4. 上述章节明确援引另一卦、而且该关联影响本次解释时，加入该卦完整章节。使用 `prepare --extra '卦名'` 可重复添加。

用户只要“先解卦辞”时：仍按上述范围理解，但先只交付卦辞层，不抢答动爻判断。用户要求所有相关原文时：以真实页范围和段落列全，不以短摘要替代；很多原文可写为工作区 Markdown 文件后提供链接。不把“相关原文”自动扩大成输出整个版权书籍。

## 版本与定位

本技能携带用户原书的未修改副本，避免依赖微信缓存或旧工作区。已确认版本共 146 个 PDF 页，正文纸本 1–136 页，正文 PDF 页=纸本页+10。引用要同时标明这两个页码。

`book-index.json` 存放源指纹、64 卦和八卦线码、章节页界、146 页文字层审计和已知疑字。它只用于定位和校验，不能替代章节正文。全书审计不等于全书逐字人工校勘，未检测到乱码也不等于没有错字。

原书 PDF：`references/book/人间道.pdf`。每次 `prepare` 首尾都核对 SHA-256；不匹配就停止，不把新的 PDF 哈希自动登记成原书，不联网拿一个相近版本继续。

## 工具执行

优先定位可用的 bundled Python，其中需要 `pdfplumber`、`pypdfium2`。`hexagram.py` 不需要这两个包；只有来源读取与渲染需要。若当前工具无法读 PDF 或看图，报告具体缺项并暂停原书解读，不说“已完整阅读”。本技能不依赖另一技能是否安装，也不需要专用插件。

使用新空目录生成包，例如在任务工作区内的 `tmp/readings/独立本次目录`；运行脚本时用绝对路径，不能假定技能当前目录就是 cwd。`--out` 是读取包路径，不是原书路径。包包含：

- `manifest.json`：主变卦、动爻、取辞选择、问题、必读页、每页文件指纹和已知疑字。
- `pages/pdf-NNN.md`：重新抽取的原页全文文字层，另提供根据字符密度估计边界的左右栏候选文本。
- `pages/pdf-NNN.png`：本次从原书渲染的整页图像。
- `reading-log.json`：未确认的逐页阅读和疑字记录。

逐页读取完整 Markdown，截断继续。逐张实际查看 PNG；长页或小字可重新高分辨率查看来源局部，不能只看图片缩略图就认定已读。混合栏页的阅读顺序依据原页分区与辞句，不能简单把整页左栏读完再右栏而将跨栏段落截断。分栏候选只是辅助，不是“已还原正文”。

每页必须确认三件不同的事：

| 字段 | 真实含义 |
|---|---|
| `text_read` | 完整读取此页文字输出，没有被截断的尾部 |
| `image_viewed` | 实际查看此页图像，核实图和文字层未包含的内容 |
| `layout_verified` | 核实双栏/跨栏/段落对应关系，未将别段拼接为引文 |

只有实际完成，才更新对应字段为 true。不要运行一键把全部字段改为 true 的命令。每个新读取包有独立 packet_id，不挪用上次记录。验证器只检查记录、来源和文件覆盖，不证明实际阅读或理解；不得把测试中自动生成的合成记录用于真实问卦。

`verify` 拒绝缺页、来源改变、页文件改变、阅读未确认、疑字未处理和关键文字不清。通过后依然必须如实表述个人阅读行为，不说“程序保证我理解了”。

## 文字识别、疑字与校勘

保留原书繁体、异体及原标点，不对 source text 自动简繁转换、纠错、用常见经文补齐。整理换行可以，但不能改变辞句、把作者解释混入易辞。简体转写与原文分别标注。

本版有两处已知待校勘内容：

- 正文书页 2 / PDF 12 的文字层“用鲍陽剛之道”：不要自行改为更顺畅的字。
- 正文书页 135 / PDF 145 的文字层“碣火求珠之課”：语义不常见，保留待核对。

只在实际涉及该页时纳入本次疑字处理；不能称这是全书仅有的两个问题。未确认的图中小字、新错字、缺字或段落顺序也记入 additional_unknowns。

已知疑字字段：`pdf_page`、`source_text_layer`、`status`、`note`、`blocks_conclusion`。

- `preserved-unresolved`：看过原页后仍不能确认，保留疑点并披露。
- `confirmed-from-page`：原页能够确认该印刷字，说明查看证据；能确认印刷内容不代表其含义没有争议。
- `corrected-with-evidence`：有实际、明确的可靠校勘依据才可记录；默认不联网搜另一版本擅自纠正，且同时保留本书原字和改字。
- `unreviewed` 不可通过阅读验证。

note 写真实证据或无法确认的原因。blocks_conclusion 为布尔值：若关键爻辞、卦辞、图意因此不明确，记 true，暂停其影响的判断并请用户给清晰图片/确认字；其余部分可先解释。非关键歧义可 false，但不能隐瞒。

新发现疑字记录示意：

```json
{"pdf_page":92,"text":"九三辞句末字无法识别","note":"实际看图后，末字分辨率不足；需要更清晰原页","blocks_conclusion":true}
```

示意不是可直接勾选的模板；字段中要写真实所见。没有发现新疑点用空列表，不能在未看原页时断言“无识别问题”。

## 原文、书中解释、本次推断

严格区分这三层：

1. 易辞原文：卦辞、彖传、象传、爻辞及爻象，按书中实际标记分别摘录。书内标记若与通常分类不同，不悄悄替换，先按来源注明。
2. 作者解释：卦图象解、故事、义理阐释。整段原文与概述要分别标明；概述不能加引号冒充逐字引用。
3. 本次推断：把书中象义运用于此人、此事、此期限的推理。明确具体映射由助手提出，不把现代单位名、待遇或录用进度说成书中原话。

标示例：“《人间道》正文书页 81（PDF 91），家人卦辞：……”；随后说明“书中如何解释”和“针对本次问题，我据此推断”。不要先背常见卦辞再去索引找个页码装成读取过。

对源 PDF 在回答中提供一次实际本地来源链接；当前客户端若支持 PDF 原文引用，可以用 `:codex-file-citation{path="原书绝对路径" purpose="source"}` 并在邻近文字标纸本/PDF页码。不要引用渲染 PNG 代替原书，不暴露内部工具 ref id。

## 主证据与变卦

完成全部阅读后按程序 selection 使用主辅文本；不是读到一个“吉”字就跳过前后限制。结合彖象与作者解释，保留辞中条件、戒慎、过程和利弊。

完整读变卦不意味着它的每一爻都能作主爻。一、二动主证据是本卦动爻；四、五动才按规则取变卦未变位置。三动明确通行简化法。想额外合参变卦整体时，明确这是背景扩展，不把它冒称必然未来或另一条主爻。

## 问现实问题

先辨认用户要的是预测结果、择业建议还是理解卦意。若“去哪工作”无法辨认且会改变答案，问一句澄清，或先给不依赖该区别的卦辞解读并说明后续所需信息；不能暗中把“会去哪”变成“建议去哪”。

没有新选项时，不自动使用以前的电规总院、国网总调、浙江省调名单。没有实际岗位信息时，不从“总院”“省调”等字面猜单位文化、福利或前景；可说明需要哪些现实信息才能比较。

不能“一条爻对应一个单位”，也不能据两动就分配两个选项。若能提出象义对应，必须交代所用现实事实、书中依据、推理桥梁及不确定性。多选题若资料不足，就不硬选一个名称。

求职解释是传统文化参考，不是招聘事实；不编造概率、确定 offer、具体日期等缺乏依据的信息。用书中的医学、法律、投资、性别或历史观念作现实事实判断时，遵守当前更高优先级核验和安全要求；不能以“书是唯一来源”为由免除它们。若用户要纯书中解释，明确是在解释来源观点，而不是认定其客观正确。

## 源更新与公开发布

默认本地使用。用户要求 GitHub 发布时另确认目标仓库、可见性和哪些材料获准上传；不能由创建技能自动推定公开原书版权授权。此技能的本地副本和来源引用不等于公开传播授权。

指纹改变时只暂停并确认版本。维护者另生成候选索引，全书重新审计、页界复核，显式采用后才能重新解读，不修改当前阅读包将失配伪装成成功。
